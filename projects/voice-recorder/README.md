# Voice Recorder

## About the project
To create a voice recorder using different libraries available in python. The file saved is a NumPy array of recorded audio. 

## Concepts Involved
- sounddevice
- wavio
- scipy


## Run
`pip install sounddevice`
`pip install wavio`
`pip install scipy`
`cd python-mini-projects/projects/voice-recorder`
`python main.py`
